\begin{abstract}
Phase 7 validates the wind speed forecasting and derivatives pricing framework across all five competing models through rigorous hypothesis testing and quantifies the economic cost of using a geographic proxy (Bologna 10\,m) instead of an aligned dataset (Nordfriesland 100\,m, Dataset B). Diebold-Mariano forecast tests confirm that AR(4) significantly outperforms the persistence benchmark (RMSE = 0.7802 vs 0.8868, $DM = 8.26$, $p < 0.001$), with a 12\% improvement. AR(4)+GARCH and CAR(4) variants share the same 1-step conditional mean as AR(4) and therefore achieve identical point-forecast RMSE; GARCH and NIG add distributional value (interval forecasts, tail risk) rather than point accuracy. GARCH(1,1) diagnostics (Ljung-Box test on squared residuals, ARCH-LM test) confirm adequacy of conditional heteroskedasticity modeling. Value of Information (VoI) analysis reveals a 93.8\% mispricing in model-implied variance swap fair strikes when using the Bologna proxy ($K_{\text{var}}^B(A) = 0.0544$ vs $0.8735$ for aligned Dataset B), driven by Bologna's 8.8× lower seasonal volatility ($C_0$). Height correction (Hellmann exponent 2/7, scaling factor 1.93) reduces the mispricing to 88\% but does not resolve the fundamental geographic misalignment. CAWS (Cumulative Accumulated Wind Speed) hedging simulation on four non-overlapping annual observations yields CVaR$_{5\%} \approx -0.121$\,m/s. Phase 7 establishes the methodology validation framework for Phase 7 Dataset B and quantifies the premium justifiable for upgrading from proxy to aligned data.
\end{abstract}

\section{Introduction: Validation Framework and Value of Information}

The complete wind speed modeling pipeline spans Phases 1--6, building from empirical distribution analysis (Phase 1) through ARMA/GARCH dynamics (Phases 2--3) to continuous-time derivatives pricing (Phases 5--6). Phase 7 serves two critical functions:

\begin{enumerate}
\item **Forecast Validation**: Rigorous statistical testing of competing models' predictive accuracy at multiple horizons, using procedures robust to non-normal residuals and heteroskedasticity.

\item **Derivatives Pricing Validation**: Quantifying the economic cost of misspecification (geographic proxy vs. aligned data) through the Value of Information (VoI) metric---the mispricing that a practitioner would avoid by upgrading data sources.
\end{enumerate}

\textit{[Technical Note: Value of Information is an economic concept from decision theory: the expected improvement in decision quality (utility) from obtaining perfect information about an uncertain parameter. In derivatives pricing, VoI quantifies the expected loss from pricing with a biased model (e.g., a proxy dataset) versus using the true underlying distribution. For wind derivatives, this is the gap between the model-implied fair strikes using Bologna (proxy) versus Nordfriesland (aligned) data. The gap reflects both model error and data mismatch.]}

\section{Diebold-Mariano Forecast Comparison: Model Hierarchy}

\subsection{Methodology: DM Test with Harvey et al. Small-Sample Correction}

The Diebold-Mariano (DM) test compares the predictive accuracy of two competing forecasts without restricting them to be nested. For two models producing 1-step-ahead forecast errors $e_{1,t}$ and $e_{2,t}$, the DM statistic is:
\begin{equation}
DM = \frac{\bar{d}}{\sqrt{\widehat{\text{Var}(d)}}},
\end{equation}
where $d_t = e_{1,t}^2 - e_{2,t}^2$ is the loss differential (squared error comparison) and $\bar{d}$ is the sample mean.

For small samples, Harvey, Leybourne, and Newbold (1997) apply a correction:
\begin{equation}
DM_{\text{corrected}} = DM_{\text{raw}} \times \sqrt{\frac{N-1}{N}},
\end{equation}
where $N$ is the sample size. We compare all models against the persistence benchmark (random walk) and test $H_0$: predictive accuracy is equal.

\textit{[Technical Note: The DM test is powerful against one-step-ahead forecasts even when residuals are non-normal or heteroskedastic (it tests squared errors, which are more robust). However, it loses power at longer horizons because forecast errors become dependent. For wind speed, the ACF of $\tilde{W}(t)$ decays quickly (AR(4) model), so 1-step tests are most reliable.]}

\subsection{Results: Five Competing Models}

We compare:
\begin{enumerate}
\item \textbf{Persistence}: $\hat{\tilde{W}}(t) = \tilde{W}(t-1)$ (no forecasting skill)
\item \textbf{AR(4)}: $\hat{\tilde{W}}(t) = \sum_{j=1}^4 \beta_j \tilde{W}(t-j)$ (Phase 2, fixed coefficients)
\item \textbf{AR(4)+GARCH}: Mean forecast from AR(4), with conditional variance scaling
\item \textbf{CAR(4)+Gaussian}: Euler discretization of CAR(4) SDE; 1-step mean equals AR(4)
\item \textbf{CAR(4)+NIG}: CAR(4) with Normal-Inverse-Gaussian noise; residuals normalized by NIG scale $\delta$
\end{enumerate}

\textbf{Key Findings}:

1. **AR(4) vs Persistence**: RMSE improves by 12.0\% ($0.7802$ vs $0.8868$), and the DM statistic ($8.27$) is highly significant, rejecting the null of equal accuracy. AR(4) incorporates valuable lagged information.

2. **AR(4)+GARCH has the same 1-step RMSE as AR(4)** (0.7802): GARCH models the conditional variance $h(t)$, not the conditional mean. The 1-step-ahead point forecast is identical to AR(4), so RMSE is unchanged. GARCH adds value for prediction intervals, VaR estimates, and derivatives pricing, but not for point-forecast accuracy at daily frequency.

3. **CAR(4)+Gaussian equals AR(4)**: By Euler discretization equivalence, the 1-step conditional mean from CAR(4) is identical to AR(4), so RMSE and DM statistics are equal. CAR(4) enables continuous-time pricing (options, variance swaps) in later phases without sacrificing forecast accuracy.

4. **CAR(4)+NIG has the same 1-step RMSE as AR(4)** (0.7802): symmetric NIG ($\beta = 0$) has the same conditional mean as a Gaussian CAR(4), so point forecasts are identical. NIG adds value for tail-risk assessment and options pricing by accurately fitting the heavy-tailed innovation distribution, but does not change the 1-step conditional mean.

\textit{[Technical Note: Models (b)--(e) in the hierarchy share the same 1-step conditional mean but differ in higher moments. GARCH refines the second moment; NIG refines the distributional shape (kurtosis, tails). These refinements matter for interval forecasts and options pricing but are not visible in RMSE comparisons, which measure only squared mean errors. The AR(4) RMSE of 0.7802 is the benchmark for 1-step point accuracy.]}

\section{GARCH Volatility Diagnostics}

\subsection{Ljung-Box and ARCH-LM Tests}

To validate that GARCH(1,1) has adequately captured conditional heteroskedasticity, we test whether standardized residuals $z_t = \hat{\eta}_t / \sqrt{h_t}$ are white noise:

**Ljung-Box Test** on $z_t^2$ (testing for remaining ARCH effects):
\begin{equation}
LB(p) = n(n+2) \sum_{k=1}^{p} \frac{\hat{\rho}_k^2}{n-k} \sim \chi^2_p.
\end{equation}

**ARCH-LM Test** on squared residuals (Lagrange multiplier specification test):
\begin{equation}
\text{LM} = nR^2 \sim \chi^2_q,
\end{equation}
where $R^2$ is from regressing $z_t^2$ on $z_{t-1}^2, \ldots, z_{t-q}^2$.

\textbf{Results (Dataset A)}:
\begin{itemize}
\item LB test on $z_t$ (lag 5):  p-value = 0.58 (no serial correlation)
\item LB test on $z_t$ (lag 10): p-value = 0.64
\item LB test on $z_t^2$ (lag 5):  p-value = 0.13 (no remaining ARCH)
\item LB test on $z_t^2$ (lag 20): p-value = 0.21
\item ARCH-LM (lag 5):  p-value = 0.42 (no heteroskedasticity)
\end{itemize}

All tests show $p > 0.05$, indicating GARCH(1,1) has adequately removed conditional heteroskedasticity. The standardized residuals $z_t$ are approximately white noise.

\textit{[Technical Note: A large p-value ($>$0.05) means we fail to reject the null that residuals are white noise---this is the desired outcome. If LB($z_t^2$, lag 20) had $p < 0.05$, it would indicate GARCH has not fully captured volatility clustering, suggesting a higher-order model (GARCH(2,1) or TARCH) might be necessary. Our result validates GARCH(1,1) as adequate for Dataset A.]}

\section{Value of Information: Dataset A vs Dataset B}

\subsection{Geographic Misalignment and Height Correction}

The fundamental issue with Dataset A (Bologna 10\,m proxy) is that it does not align with the German wind market being hedged. Two corrections can be applied:

Two corrections can be applied:

\begin{enumerate}
    \item \textbf{Raw comparison}: Direct comparison of
    $K_{\mathrm{var}}^{AB}$ values without adjustment.

    \item \textbf{Height correction}: Scaling variance from
    10\,m to 100\,m using the wind power law.
\end{enumerate}
The power law profile predicts wind speed scales with height as:
\begin{equation}
v(h) = v(h_0) \left( \frac{h}{h_0} \right)^{\alpha},
\end{equation}
where $\alpha \approx 1/7$ (wind profile power law exponent \citep{PetersonHennessey:1978}) for neutral conditions. Since variance scales as velocity squared:
\begin{equation}
\text{Var}(h) = \text{Var}(h_0) \left( \frac{h}{h_0} \right)^{2\alpha} = \text{Var}(h_0) \left( \frac{h}{h_0} \right)^{2/7}.
\end{equation}

For $h_0 = 10$\,m and $h = 100$\,m:
\begin{equation}
\text{correction factor} = \left( \frac{100}{10} \right)^{2/7} = 10^{2/7} = 1.9307.
\end{equation}

\textit{[Technical Note: The wind profile power law exponent $\alpha = 1/7$ is empirical (Peterson \& Hennessey 1978, measured from meteorological profiles), not theoretical. It varies with surface roughness and stability (more irregular terrain → larger $\alpha$; stable air → smaller $\alpha$). For offshore wind (smooth ocean surface), $\alpha \approx 1/10$, giving a factor $10^{2/10} = 1.585$. We use 1/7 for coastal Germany, a reasonable middle ground.]}

\textbf{Root Causes of Mispricing}:

The formula $K_{\text{var}}^B(h) = h \times C_0$ decomposes the gap:
\begin{equation}
\frac{K_{\text{var}}^B(B)}{K_{\text{var}}^B(A)} = \frac{h_{t_0,B}}{h_{t_0,A}} \times \frac{C_{0,B}}{C_{0,A}} = \frac{0.7511}{0.4137} \times \frac{1.163}{0.13138} = 1.815 \times 8.846 \approx 16.1.
\end{equation}

The dominant driver is the Fourier constant: $C_{0,B} / C_{0,A} = 8.846$. This reflects that Bologna's seasonal wind volatility (as captured by the Fourier decomposition in Phase 1) is approximately 1/9th of Nordfriesland's seasonal volatility at 100\,m. The secondary driver is $h_{t_0,B} / h_{t_0,A} = 1.815$: Nordfriesland's GARCH-estimated conditional volatility is nearly twice as high as Bologna's.

\textit{[Technical Note: The $C_0$ gap (9×) is not primarily a height effect, but a regional climate difference. Nordfriesland is in Germany's high-wind corridor (North Sea coast, Atlantic frontal systems). Bologna is in the Mediterranean, with lower mean wind and seasonal variation. Height correction accounts for typical meteorological effects, but cannot eliminate regional differences in weather patterns.]}

\section{CAWS Hedging Simulation: Practical Wind Risk Management}

\subsection{CAWS Definition and Fair Strike}

Cumulative Accumulated Wind Speed (CAWS) is a normalized rolling annual mean:
\begin{equation}
\text{CAWS}_t = \frac{1}{252} \sum_{s=t-251}^{t} w_s,
\end{equation}
where $w_s$ is the daily mean wind speed (m/s). Normalisation by 252 ensures comparability across heights (Dataset A: $\bar{W} \approx 2.47$~m/s at 10~m; Dataset B: $\bar{W} \approx 8$~m/s at 100~m).

The fair strike for a CAWS swap is the unconditional mean:
\begin{equation}
K_{\text{CAWS}} = \mathbb{E}[\text{CAWS}_t].
\end{equation}

A producer who buys a CAWS swap at this strike receives payoff $\text{Payoff}_t = K_{\text{CAWS}} - \text{CAWS}_t$, positive when wind is below the fair strike.

\subsection{P\&L Distribution and Risk Metrics}

\textit{[Note on methodology: distribution metrics (Sharpe ratio, VaR$_{5\%}$, CVaR$_{5\%}$) are computed on \textbf{non-overlapping annual observations} — one annual mean wind speed per calendar year — rather than on the rolling daily CAWS series. This avoids the serial-correlation bias induced by the 252-day overlapping window construction: adjacent rolling-window values share 251 of 252 observations and are therefore almost perfectly correlated, which would render standard deviation and quantile estimates unreliable. The time-series plot still uses the rolling CAWS for visual continuity.]}

\section{Delta Sensitivity and Stress Analysis}

The model-implied fair strike $K_{\text{var}}^B = h \times C_0$ has a closed-form sensitivity to the GARCH conditional variance state:
\begin{equation}
  \frac{\partial K_{\text{var}}^B}{\partial h} = C_0.
\end{equation}
For Dataset~A, $C_0 = 0.13138$, so each unit increase in the GARCH variance state shifts the fair strike by $0.13138$ units. This is the \textit{delta} of the variance swap with respect to the volatility state.

\paragraph{Stress scenario.} If a persistent low-wind period (e.g., a European wind drought) doubles the GARCH conditional variance from $h_{t_0} \approx 0.414$ to $h_{\text{stress}} = 2 h_{t_0} \approx 0.828$, the fair strike shifts by:
\begin{equation}
  \Delta K_{\text{var}}^B = (h_{\text{stress}} - h_{t_0}) \times C_0 = h_{t_0} \times C_0 = K_{\text{var}}^B(h_{t_0}) \approx 0.054.
\end{equation}
This small absolute shift (relative to the Track A fair strike of 114) further confirms that the model-implied strike is primarily driven by $C_0$ (the seasonal component) and is insensitive to GARCH state fluctuations at Dataset~A's low-variance site.

\section{Forecast Error Distribution: Normality and Tail Risk}

\subsection{Jarque-Bera Normality Tests}

For each model's 1-step-ahead residuals, we test normality:
\begin{equation}
JB = n \left( \frac{S^2}{6} + \frac{(K-3)^2}{24} \right) \sim \chi^2_2,
\end{equation}
where $S$ is skewness and $K$ is kurtosis.

\textbf{Key Results}:

\textbf{Key Results}

\begin{enumerate}
    \item \textbf{Raw residuals are non-normal:}
    Both Persistence and AR(4) residuals exhibit excess kurtosis
    (heavy tails), failing the normality test.

    \item \textbf{NIG normalization succeeds:}
    Dividing AR(4) residuals by the NIG scale parameter
    $\delta = 2.087$ yields residuals with JB p-value $=0.160$,
    failing to reject normality. This suggests that the NIG
    distribution captures the heavy tails of wind-speed innovations
    better than a Gaussian distribution.

    \item \textbf{Implication for options pricing:}
    Option prices depend on tail probabilities. Gaussian
    distributions (implicit in Black--Scholes) underestimate the
    cost of out-of-the-money options (equivalently, they
    overestimate OTM probabilities). NIG-adjusted pricing would
    correct this bias, particularly for far-OTM calls and puts on
    wind speed.
\end{enumerate}

{\itshape
Technical Note: The NIG distribution has two tail parameters:
$\alpha$ (tail heaviness) and $\beta$ (skewness). Dataset A anchors from
Phase 4 give $\alpha = 4.374$, $\beta = 0$ (symmetric). The
$\delta = 2.087$ is the scale.
}

\textbf{Key Takeaways}

\begin{enumerate}
    \item \textbf{Forecast hierarchy is validated:}
    AR(4) is the reliable one-step-ahead benchmark. CAR(4)
    preserves forecasting accuracy while enabling derivatives
    pricing. NIG residuals provide additional insight into
    tail risk.

    \item \textbf{GARCH is sufficient:}
    Diagnostic tests confirm that GARCH(1,1) adequately models
    conditional volatility. The standardized residuals behave
    as white noise.

    \item \textbf{Geographic mismatch dominates pricing error:}
    The observed 88--94\% mispricing is primarily driven by
    Bologna's low seasonal volatility ($C_0$), rather than
    model misspecification. This issue cannot be corrected
    simply by adjusting for turbine hub height.

    \item \textbf{Dataset upgrade is economically justified:}
    For a 100 MW wind farm generating approximately
    €50 million in annual revenue, an 88\% underpricing
    of variance swap strikes could translate into losses of
    hundreds of millions of euros over a 5--10 year contract
    horizon if the producer hedges using the proxy-derived
    fair strike.

    \item \textbf{Phase 7 Dataset B will show:}
    Replicating this validation framework on Dataset B
    (Nordfriesland ERA5, 100 m, 10-year) will serve both as
    confirmation and as a test of data quality. Applying the
    same methodology to a geographically aligned dataset
    should improve pricing accuracy and substantially reduce
    geographic bias.
\end{enumerate}
